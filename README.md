# Retro Gamepads Input Plug-in

Additional (à la carte) gamepad type and icon configurations for [Input for GameMaker 2024.8](https://github.com/offalynne/Input)

### Added gamepad types
- SNK Neo Geo
- Sega Saturn
- Nintendo 64
- Nintendo GameCube

To omit types, delete config scripts and associated devices will fallback as usual.
    
### Broad device support
- Classic/mini console gamepads
- Nintendo Switch Online gamepads
- Retro-bit, Retroflag, Retro Fighters gamepads
- 8BitDo modkits and gamepads
- Mayflash adapters
- Raphnet-tech adapters
- Many more (50+ devices)

### Usage

Refer to icon configuration function found in `__InputRetroIconConfig[…]` scripts. To omit types, delete the associated config scripts, and categorized devices will fallback as usual.
